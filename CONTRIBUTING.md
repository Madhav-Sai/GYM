# Contributing

myGym is a personal project by Madhav, built on [openGym](https://github.com/DuarteSantos8/openGym).
Issues and suggestions are welcome through GitHub. By contributing you agree your contribution is licensed under
the AGPL-3.0, like the rest. There is no contributor agreement to sign.

Before sending a change, run the tests: `cd api && npm test` and `cd frontend && npx vitest run`.
Changes to the parts that came from openGym are better sent to openGym itself when they're general.
